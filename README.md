# Deep Rock Galactic Equipment Supplier Page Bootstrap

## Overview
This is a fictional supplier web page for the mining company Deep Rock Galactic. This web page was created to demonstrate my proficiency with the Bootstrap CSS framework.<br>
A preview of what this project looks like when deployed can be viewed on Vercel at this link: https://drg-equipment-supplier-page-bootstr.vercel.app/

## Tech Stack
- HTML5
- Bootstrap CSS
